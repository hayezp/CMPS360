# CMPS 360 - Java Programming

## About This Repository

This repository contains my assignments and projects for CMPS 360. I will be using Java and Visual Studio Code throughout this course.

## Module 1

For Module 1, I completed a guided lab and two assignments.

- **Guided Lab:** Created a Hello World program that displays messages in the terminal, "Hello, CMPS360! Welcome to Java Programming". 
- **Assignment 1:** Created a Student Grade Calculator that calculates the average of three grades and shows if the student passed or failed.
- **Assignment 1B:** Created a simple Inventory Application that calculates the total value of two products and then displays the results in the terminal and in a pop-up window.

## How to Run

Open the Java programs in Visual Studio Code and click Run above the main method, all of the results will appear in the terminal. The Inventory Application also displays as a pop-up window.
